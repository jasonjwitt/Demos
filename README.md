# Batch File Processor (Demo Version)

This repository contains a **stripped-down demo version** of a Python-based batch file processor. The original version is used in client-facing automation projects to **normalize** and **summarize data** from **fixed-width** and **delimited** text files. This demo version showcases the high-level flow and capabilities without including proprietary parsing logic or modular enhancements.

### 🚀 Features Demonstrated in This Demo:
- Basic **configuration loader**
- Basic **parsing of delimited files** (CSV-like)
- **Header/trailer validation**
- **Record summarization by category**
- **Text-based reporting**

### 🔧 How It Works  
This script assumes the input file follows this basic structure:  
- Input files include a **header**, multiple **data lines**, and a **trailer**.
- The **config file** defines the structure and rules for processing (e.g., delimiter, field names, required fields).
- The script performs **normalization**, **validation**, and **summarization** of key values.

---

### Script Flow  
**Input File**  
   ↓  
**Normalize (delimited → CSV)**  
   ↓  
**Validate Header & Trailer**  
   ↓  
**Summarize Values by Category**  
   ↓  
**Generate Report**

### 🗂️ Files  

| **File**                            | **Purpose**                                           |
|-------------------------------------|------------------------------------------------------|
| `Batch_Processor_Demo.py`           | Main demo script that processes the input data file, validates the header/trailer, parses the data, and generates a summary report. |
| `test_script.py`                    | **Test script** to **automate** the process of running the `Batch_Processor_Demo.py` script. It invokes `Batch_Processor_Demo.py`, validates its output, and compares the results to an expected report. |
| `configs/default_config.json`       | Example configuration file defining the structure and rules for parsing the input file (e.g., delimiter, field names). |
| `sample_input.txt`                 | Sample input file to be processed by the demo script. Contains data with a header, data lines, and trailer. |
| `expected_output.txt`              | Expected output file for testing purposes. Used by the `test_script.py` to validate the output generated by the `Batch_Processor_Demo.py` script. |

---

### ▶️ Usage  
To run the demo script, use the following command:  
```bash
python Batch_Processor_Demo.py path/to/input_file.txt path/to/config.json
```
- The input file should follow the expected **header → data → trailer** layout.
- The config file defines whether the file is **fixed-width** or **delimited**.

To test the functionality using the **test script**, run:  
```bash
python test_script.py
```
- The test script will automatically run `Batch_Processor_Demo.py` with a sample input and compare the output to an expected result.

### Explanation of Each File:
#### `Batch_Processor_Demo.py` (Main Processing Script):
- This is the **core script** responsible for processing input data. It takes a file and a configuration file, validates the input format, parses the data, and generates a report.
- **Main features**:
  - **Validates** header and trailer.
  - **Parses** delimited file based on configuration.
  - **Summarizes** data by category.
  - **Generates a report** summarizing the parsed data.

#### `test_script.py` (Test Script):
- This script is intended to **automate** the testing of the `Batch_Processor_Demo.py` script.
- **Main features**:
  - Runs the `Batch_Processor_Demo.py` script with a specified **input file** and **config file**.
  - **Compares** the generated report to an **expected output file** to verify if the script produces the correct results.
  - Helps automate the **validation** process, ensuring the `Batch_Processor_Demo.py` script works as expected.
